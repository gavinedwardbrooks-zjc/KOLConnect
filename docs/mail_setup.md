# 邮箱配置指南

本指南帮助你把邮箱连接到 KOLConnect，用于同步达人往来邮件和跟进状态。

> KOLConnect 当前不会直接发送邮件。邮箱连接用于读取收件箱，并在服务商支持时读取“已发送”文件夹。

[返回外部服务配置总指南](EXTERNAL_SYNC_SETUP_GUIDE_ZH.md)

## 邮箱功能可以做什么

- 手动同步收件箱。
- 在服务商支持时同步已发送邮件。
- 将历史邮件与已有达人邮箱匹配。
- 显示待我回复、待对方回复、稍后处理等跟进状态。

当前使用标准 IMAP 方式连接邮箱。

> **Outlook / Microsoft 365 不受支持。** KOLConnect 不支持 Outlook / Microsoft 365 邮箱，后续也不计划加入该支持。由于 Microsoft 对第三方邮箱客户端的认证和接入方式有限制，KOLConnect 当前的邮箱同步方案不会兼容 Outlook / Microsoft 365。请不要尝试通过普通密码、OAuth 或应用密码绕过；请改用 Gmail、QQ 邮箱、网易邮箱、阿里企业邮箱或其他支持标准 IMAP 的邮箱。

## 一、先在邮箱服务商处准备

大多数邮箱需要先完成以下操作：

1. 登录邮箱网页版。
2. 在“设置”“账号与安全”或“客户端设置”中启用 IMAP。
3. 按服务商提示生成“授权码”“应用专用密码”或“第三方客户端安全密码”。
4. 保存好授权码。部分服务商只显示一次。

授权码是专门给第三方邮件客户端使用的密码。服务商要求授权码时，不要填写邮箱网页版的登录密码。

## 二、KOLConnect 中有哪些字段

进入“邮箱账户”，点击“新增邮箱账户”。

| 字段 | 如何填写 |
| --- | --- |
| `账户名称` | 方便自己识别，例如“商务 Gmail” |
| `邮箱类型` | Gmail、网易邮箱、阿里邮箱或自定义邮箱 |
| `邮箱地址` | 完整邮箱地址 |
| `发件人名称` | 显示名称，可按团队习惯填写 |
| `IMAP Host` | 收件服务器地址 |
| `IMAP Port` | 收件服务器端口，通常为 993 |
| `SMTP Host` | 发件服务器地址 |
| `SMTP Port` | 发件服务器端口，通常为 465 或 587 |
| `用户名` | 通常填写完整邮箱地址 |
| `密码/授权码` | 服务商生成的授权码或应用专用密码 |
| `启用` | 勾选后，该账户会参与邮件同步 |

当前界面没有单独的“SSL/TLS”开关。请使用服务商推荐的加密端口：IMAP 通常使用 993，SMTP 通常使用 465 或 587。

虽然 KOLConnect 不发送邮件，“测试连接”仍会同时验证 IMAP 和 SMTP 登录，所以当前表单需要填写两组服务器信息。测试不会发送真实邮件。

填写后：

1. 点击“测试连接”。
2. 测试通过后点击“保存邮箱账户”。
3. 进入“邮件”页面，手动同步收件箱。
4. 在“邮件跟进”页面查看匹配和跟进状态。

## 三、常用邮箱参数

服务商可能调整安全策略。下表适用于当前常见配置；如你的邮箱后台或企业管理员给出了不同参数，以服务商或管理员提供的值为准。

| 邮箱 | 邮箱类型 | IMAP Host | IMAP Port | SMTP Host | SMTP Port | 密码字段 |
| --- | --- | --- | --- | --- | --- | --- |
| Gmail / Google Workspace | Gmail | `imap.gmail.com` | `993` | `smtp.gmail.com` | `587` | Google 应用专用密码 |
| QQ 邮箱 | 自定义邮箱 | `imap.qq.com` | `993` | `smtp.qq.com` | `465` | QQ 邮箱授权码 |
| 网易 163 | 网易邮箱 | `imap.163.com` | `993` | `smtp.163.com` | `465` | 网易客户端授权码 |
| 网易 126 | 网易邮箱 | `imap.126.com` | `993` | `smtp.126.com` | `465` | 网易客户端授权码 |
| 阿里邮箱 / 阿里云企业邮箱 | 阿里邮箱 | `imap.qiye.aliyun.com` | `993` | `smtp.qiye.aliyun.com` | `465` | 登录密码或第三方客户端安全密码 |

选择“Gmail”或“网易邮箱”时，KOLConnect 会自动填写部分服务器参数。网易预设默认为 163 邮箱；使用 126 邮箱时，请手工改成 `imap.126.com` 和 `smtp.126.com`。

KOLConnect 当前没有 QQ 专用选项，请选择“自定义邮箱”并手工填写。

## 四、Gmail

个人 Gmail 从 2025 年起默认启用 IMAP，不再提供单独的“启用 IMAP”开关。Google Workspace 管理员仍可能限制第三方客户端访问。

KOLConnect 当前不支持 Gmail OAuth，因此普通 Google 账号密码通常不能直接使用。推荐步骤：

1. 为 Google 账号开启“两步验证”。
2. 在 Google 账号安全设置中创建“应用专用密码”。
3. 在 KOLConnect 的“密码/授权码”中填写该应用专用密码。
4. 用户名填写完整 Gmail 地址。
5. 使用 `imap.gmail.com:993` 和 `smtp.gmail.com:587`。

参考：

- [Google：在其他邮件客户端中使用 Gmail](https://support.google.com/mail/answer/7126229?hl=zh-Hans)
- [Google：应用专用密码](https://support.google.com/accounts/answer/185833?hl=zh-Hans)

## 五、QQ 邮箱

1. 登录 QQ 邮箱网页版。
2. 在“设置”中的账号或客户端服务区域启用 IMAP/SMTP。
3. 按页面提示生成授权码。
4. 在 KOLConnect 中选择“自定义邮箱”。
5. 用户名填写完整 QQ 邮箱地址，密码填写授权码。

常用参数为 `imap.qq.com:993` 和 `smtp.qq.com:465`。可从 [QQ 邮箱帮助中心](https://service.mail.qq.com/) 查看当前说明。

## 六、网易 163 / 126

1. 登录网易邮箱网页版。
2. 打开“设置” → “POP3/SMTP/IMAP”。
3. 启用 IMAP，并生成客户端授权码。
4. 在 KOLConnect 中选择“网易邮箱”。
5. 用户名填写完整邮箱地址，密码填写客户端授权码。

163 邮箱使用 `imap.163.com` / `smtp.163.com`；126 邮箱使用 `imap.126.com` / `smtp.126.com`。两者常用加密端口均为 IMAP 993、SMTP 465。

参考：[网易邮箱：如何开启客户端协议](https://help.mail.126.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac2a5feb28b66796d3b)

## 七、阿里邮箱 / 阿里云企业邮箱

1. 在企业邮箱后台确认已允许第三方客户端登录。
2. 如果组织启用了“三方客户端安全密码”，先生成该密码。
3. 在 KOLConnect 中选择“阿里邮箱”并手工填写服务器参数。
4. 使用 `imap.qiye.aliyun.com:993` 和 `smtp.qiye.aliyun.com:465`。

注意服务器地址以 `imap` 开头，不是 `Map.qiye.aliyun.com`。

参考：[阿里云：阿里邮箱 IMAP、SMTP 地址与端口](https://help.aliyun.com/zh/document_detail/36576.html)

## 八、企业邮箱 / 自定义邮箱

如果上表没有你的服务商，请向邮箱管理员索取：

- IMAP 服务器
- IMAP 端口
- 是否要求 SSL/TLS
- SMTP 服务器
- SMTP 端口
- 用户名格式，是完整邮箱地址还是账号名
- 登录密码、授权码或应用专用密码
- 是否允许第三方客户端使用 IMAP/SMTP

在 KOLConnect 中选择“自定义邮箱”，按管理员提供的参数填写。

## 九、常见问题

| 现象 | 常见原因 | 建议 |
| --- | --- | --- |
| 无法连接服务器 | Host 拼错、端口错误、网络或防火墙阻止 | 对照服务商后台逐字检查 Host 和端口 |
| 用户名或密码错误 | 填了网页版密码，但服务商要求授权码 | 重新生成授权码，并使用完整邮箱地址作为用户名 |
| IMAP 登录失败 | IMAP 未启用，或企业管理员禁止第三方客户端 | 在邮箱后台启用 IMAP，必要时联系管理员 |
| SMTP 登录失败 | SMTP Host/Port 错误，或服务商未开放该端口 | 使用服务商推荐的加密端口 |
| Gmail 拒绝登录 | 未使用应用专用密码，或两步验证未开启 | 开启两步验证并创建应用专用密码 |
| 网易连接失败 | 163 与 126 服务器地址混用 | 按邮箱后缀选择正确的 Host |
| 阿里邮箱无法解析服务器 | 把 `imap` 误写成了 `Map` | 使用 `imap.qiye.aliyun.com` |
| 已发送邮件没有出现 | 服务商未标记标准“已发送”文件夹，或文件夹不可访问 | 确认网页版存在已发送邮件；该账户仍可同步收件箱 |

不要把邮箱密码、授权码、完整邮件内容或包含私人地址的日志发到公开 Issue。
