# KOLConnect v0.1.2 使用说明

## 1. 软件介绍

KOL联系助手用于帮助海外运营同事整理达人信息：

- 创建并管理达人抓取任务
- 抓取 TikTok、Instagram、YouTube 达人主页信息
- 人工审核和补充达人名称、邮箱、WhatsApp、备注
- 同步达人和达人账号到飞书四表
- 管理邮箱账户、识别达人回复并同步联系状态

## 2. 安装与打开

1. 双击 `KOLConnect.exe` 打开软件。
2. 首次打开时等待主界面加载完成。
3. 日常使用请从桌面快捷方式或软件安装目录打开。

> 截图位置：软件主界面

## 3. 首次配置

进入“设置”页面，填写管理员提供的信息：

1. 飞书 App ID
2. 飞书 App Secret
3. 飞书 App Token
4. 达人表 Table ID
5. 达人账号表 Table ID

填写完成后，点击“保存飞书配置”。

如果需要使用邮件功能，再进入“邮件发送”页面，新增邮箱账户并填写：

- 账户名称
- 邮箱地址
- IMAP / SMTP 地址和端口
- 用户名
- 密码或授权码

点击“测试连接”，确认状态正常后再使用收件箱同步。

> 截图位置：飞书配置

## 4. 创建抓取任务

1. 进入“邮箱抓取”页面。
2. 填写任务名称，例如“巴西 TikTok 游戏达人 7 月”。
3. 在链接输入框粘贴达人链接，每行一个。
4. 选择目标平台：全部、TikTok、Instagram 或 YouTube。
5. 点击“创建任务”。

软件会识别链接平台，并自动过滤不属于当前目标平台的链接。

> 截图位置：创建抓取任务

## 5. 抓取达人

1. 在任务列表中点击需要执行的任务。
2. 确认当前选中的任务名称、平台和链接数量。
3. 点击“开始抓取”。
4. 查看完成数量、失败数量和运行日志。

Instagram 抓取首次使用时，可能需要在自动打开的浏览器中手动登录 Instagram。登录后，软件会继续复用该登录状态。

> 截图位置：任务列表和抓取进度

## 6. 审核数据

1. 进入“审核结果”页面。
2. 选择需要审核的任务。
3. 检查达人名称、邮箱、WhatsApp 和备注。
4. 对需要修正的记录直接编辑，点击该行“保存”。

平台、达人链接、账号唯一 ID、最近发布日期和抓取状态为只读信息。保存后，修改会保留在当前任务中，供后续同步使用。

> 截图位置：审核结果表格

## 7. 同步飞书四表

1. 在“审核结果”页面选择当前任务。
2. 确认名称、邮箱和人工补充信息无误。
3. 点击“同步当前任务到四表”。
4. 查看同步结果中的创建、更新、跳过和失败数量。

同步通过账号唯一 ID 识别已有达人账号。飞书中已有的人工字段默认不会被软件覆盖；软件只补充空字段。

> 截图位置：四表同步结果

## 8. 人工录入达人

当达人不是通过批量链接抓取发现时，可以使用人工录入：

1. 在任务页面打开“人工录入达人”。
2. 填写达人名称、平台、主页链接、邮箱、WhatsApp 和备注。
3. 主页链接为必填项。
4. 创建后，该记录会进入审核结果页面。
5. 审核完成后，使用“同步当前任务到四表”。

如需补充主页抓取信息，可选择该人工任务后点击“补充抓取信息”。

> 截图位置：人工录入达人

## 9. 缺失邮箱补全

当飞书达人账号表中存在主页链接但账号邮箱为空的记录时：

1. 进入“审核结果”页面。
2. 点击“扫描四表缺失邮箱”。
3. 软件会创建一个“缺失邮箱补全”任务。
4. 选择该任务并点击“开始抓取”。
5. 完成后同步当前任务到四表。

邮箱补全只会补充飞书中为空的账号邮箱，不会覆盖已有邮箱或人工维护字段。

> 截图位置：缺失邮箱补全任务

## 10. 邮件同步

### 同步收件箱

1. 进入“邮件发送”页面。
2. 确认至少有一个已启用且测试正常的邮箱账户。
3. 点击“同步收件箱”。
4. 软件会读取最近邮件，并按发件人邮箱精确匹配达人账号。

### 同步回复状态

1. 在邮件列表中确认达人回复匹配结果。
2. 点击“同步回复状态到达人表”。
3. 软件会更新允许更新的联系状态和最近联系时间。

不会自动发送邮件，也不会修改报价、标签、负责人、WhatsApp 或备注。

> 截图位置：邮件列表与回复状态同步

## 11. 常见问题

### 软件打开后没有历史任务

请确认使用的是同一个 Windows 账户。任务和设置会保存在当前 Windows 用户的数据目录中。

### 抓取失败怎么办

请检查网络、Chrome 是否已安装，以及 Instagram 是否已完成登录。单条链接失败不会停止其它链接继续抓取。

### 为什么同步后没有新增记录

请检查该账号唯一 ID 是否已存在于飞书达人账号表。已有账号会按保护规则补充空字段，而不会重复创建。

### 删除任务会删除飞书数据吗

不会。删除任务只会删除本地任务文件，不会删除已同步到飞书的数据。

### 邮件没有匹配到达人

请确认邮件发件人邮箱与飞书达人账号表中的账号邮箱完全一致。软件不会按昵称或模糊邮箱匹配。

## 12. 日常工作流程

```text
收集达人链接
-> 创建任务
-> 开始抓取
-> 审核并补充信息
-> 同步飞书四表
-> 同步收件箱并查看达人回复
```
