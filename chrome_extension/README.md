# KOL Connect 插件

## 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `chrome_extension`。

## 使用

1. 启动 KOL联系助手桌面程序。
2. 打开 TikTok、Instagram 或 YouTube 的达人主页。
3. 点击浏览器工具栏中的“KOL Connect 插件”。
4. 检查平台、用户名、名称、主页 URL、粉丝数和简介。
5. 点击“确认并发送”。

插件只创建本地人工录入任务。发送后请回到 KOL联系助手的“审核结果”页面确认，再同步到飞书四表。
