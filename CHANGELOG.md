# Changelog

All notable changes to KOLConnect are documented in this file.

## v0.1.2

### Added

- KOL and creator relationship management.
- Social account management for TikTok, Instagram and YouTube.
- Agency and Agency contact relationships, including source contacts.
- Public business email discovery and missing-email recheck tasks.
- Feishu CRM synchronization for creators and creator accounts.
- Chrome extension for manual profile collection.
- Task creation, review, pause, resume, graceful stop and heartbeat monitoring.
- Mailbox synchronization, account-email matching and manual reply-status sync.

### Fixed

- Project structure and KOLConnect brand consistency.
- Per-user application data paths and independent Chrome profile handling.
- Build configuration, application icon and portable PyInstaller spec paths.
